# Git Field Guide

A hands-on guide to Git and GitHub. Every command is explained piece by piece and shows the output you should expect. Words with a dotted underline open a plain-language definition when you click them.

## What's inside

- **11 chapters:** how Git thinks, setup, starting a repository, the daily loop, history, branches, push and pull, pull requests, undoing mistakes, merge conflicts, and `.gitignore`
- **Sandbox:** a simulated terminal that runs in the browser, with live panels for your files, the staging area, your local commits and GitHub, plus a guided exercise
- **Cheat sheet** and a searchable **glossary**

## Use it

It's a single file with no build step. Open `index.html` in any browser.

To put it online with GitHub Pages: go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save. After a minute it's live at `https://<your-username>.github.io/git-concepts/`.
